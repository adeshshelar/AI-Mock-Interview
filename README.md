
<h1 align="center"><b>QuickMock – AI Mock Interview Platform</b></h1>


QuickMock – AI Mock Interview Platform is designed to help users prepare effectively for interviews. With AI-driven question generation, real-time feedback, and answer recording, it simulates a realistic interview environment. This platform empowers candidates to enhance their skills and gain confidence for their next big opportunity.

🛠️ **Tech Stack**
 - Frontend: React
 - Database: PostgreSQL
 - ORM: Drizzle ORM
 - AI Integration: Gemini AI
 - Authentication: Clerk

**Features**

👉 Authentication : 
QuickMock integrates authentication and authorization using Clerk, enabling users to log in securely with social sign-on options (like Google or GitHub) or traditional email-password methods. It ensures secure access and appropriate permissions for all platform users.

👉 AI-Generated Questions : 
Leverage AI to simulate real interview scenarios with dynamically generated questions tailored to the user’s profile and selected domain.

👉 Answer Recording : 
Users can record their answers during mock interviews, which are securely saved for detailed feedback and future review.

👉 Instant Feedback : 
The platform provides AI-powered instant feedback on answers, helping users identify strengths and improvement areas to excel in their interviews.

👉 User-Friendly Interface : 
A clean and intuitive interface ensures seamless navigation, making it easy to access features like starting a new interview, reviewing past sessions, and exploring detailed feedback.
